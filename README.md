# 🫧 一時記憶逃し v1

いま頭に保持している考えや気づきを、忘れてまたゼロから考え直す前に退避するための軽量カードツールです。RAMあけリンク集 v1 の実証済み基盤から派生しています。

## ファイル
- `index.html`
- `style.css`
- `app.js`

## 主な機能
- URLまたはタイトルのどちらかがあれば登録可能
- localStorage保存
- 編集・個別削除・全件リセット
- 新しい順／古い順の表示切替
- JSONバックアップ書き出し
- JSON読み込み・IDベースのマージ
- 衝突時「現在を残す／読み込み側を採用／どちらも残す」
- 人間向けHTMLアーカイブ書き出し
- PC／スマホのレスポンシブ表示
- 書き出しファイル名の日付は端末ローカル日付

## 保存について
ブラウザ保存は恒久保存ではありません。JSON書き出しをバックアップとして併用してください。iPhoneではホーム画面版を本番データ置き場として使う想定です。

## GitHub Pages
静的ファイル3点（`index.html`, `style.css`, `app.js`）をリポジトリ直下に置けば公開できます。
